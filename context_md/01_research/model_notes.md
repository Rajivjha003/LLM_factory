# Model Notes

## Recommended Progression
1. Tiny scratch model: 30M-125M.
2. Fast lab model: 1B-3B.
3. Main local model: 7B-8B.
4. Stretch model: 14B.

## Base Model Evaluation Criteria
- License
- Context length
- Chat template
- SQL/code ability
- Reasoning ability
- Tool-use behavior
- Unsloth support
- vLLM support
- GGUF conversion path

## Local First Rule
A model that cannot be trained, evaluated, compressed, and served on the local machine is not the first target.
