# Chain-of-Thought Policy

## Goal
Improve reasoning without forcing unsafe or verbose public scratchpads.

## Training Allowed
- Structured reasoning traces
- Concise rationale
- Step-by-step solution for educational tasks
- Verifier feedback loops
- Tool error correction traces

## Production Output Preference
- Short diagnosis
- Key reasoning summary
- Final answer/checklist/query

## Avoid
- Long hidden scratchpad exposure
- Noisy synthetic reasoning
- Unverified chain-of-thought examples
- Reasoning that contradicts final answer
