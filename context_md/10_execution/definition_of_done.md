# Definition of Done

A task is done only when:
- The output artifact exists.
- It is documented.
- It is tested or reviewed.
- It does not violate hardware/security constraints.
- It is linked to the correct phase.
- It can be reproduced.

A model is done only when:
- It has a dataset version.
- It has a training config.
- It has eval results.
- It has a model card.
- It has known limitations.
- It has a rollback path.

A deployment is done only when:
- Health check passes.
- Smoke test passes.
- Logs are captured.
- Feedback can be collected.
- Rollback is possible.
