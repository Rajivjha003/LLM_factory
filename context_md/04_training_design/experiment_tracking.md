# Experiment Tracking

## Tool
Use W&B or MLflow.

## Track
- Base model
- Dataset version
- Training method
- Hyperparameters
- Loss curve
- Eval scores
- Peak VRAM
- Training time
- Notes/failures

`method_model_dataset_version_shortgoal`

`sft_qwen3b_sqlretail_v1_formatdiscipline`
